# Windows DHCP Server

**Category:** Windows / Network  
**Collection method:** Zabbix Agent (active)  
**Items:** 5  
**Zabbix version:** 7.4+

## Description

Windows DHCP Server monitoring — scope utilization, lease counts and service health.

## Requirements

- Zabbix Server 7.4+
- Zabbix Agent (active) configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
