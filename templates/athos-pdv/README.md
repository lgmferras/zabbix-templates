# ATHOS PDV

**Category:** Windows / Applications  
**Collection method:** Zabbix Agent 2 (active)  
**Items:** 45  
**Zabbix version:** 7.4+

## Description

ATHOS commercial POS system — PostgreSQL backup monitoring, process health and log directory size.

## Requirements

- Zabbix Server 7.4+
- Zabbix Agent 2 (active) configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
