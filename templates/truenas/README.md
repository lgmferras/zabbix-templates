# TrueNAS

**Category:** Applications / Storage  
**Collection method:** HTTP (TrueNAS REST API)  
**Items:** 87  
**Zabbix version:** 7.4+

## Description

Comprehensive TrueNAS storage monitoring — pool health, dataset usage, alerts and system info.

## Requirements

- Zabbix Server 7.4+
- HTTP (TrueNAS REST API) configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
