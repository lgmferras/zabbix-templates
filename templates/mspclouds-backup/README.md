# MSPClouds Backup Monitor

**Category:** Applications / Cloud  
**Collection method:** HTTP (MSPClouds API)  
**Items:** 11  
**Zabbix version:** 7.4+

## Description

Backup job status via MSPClouds API — last run time and job success/failure.

## Requirements

- Zabbix Server 7.4+
- HTTP (MSPClouds API) configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
