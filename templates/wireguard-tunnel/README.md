# WireGuard Tunnel

**Category:** Network / VPN  
**Collection method:** Zabbix Agent  
**Items:** 7  
**Zabbix version:** 7.4+

## Description

WireGuard VPN tunnel monitoring — handshake age, peer status and tunnel connectivity.

## Requirements

- Zabbix Server 7.4+
- Zabbix Agent configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
