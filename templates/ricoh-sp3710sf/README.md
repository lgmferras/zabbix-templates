# Ricoh SP 3710SF Printer

**Category:** Applications / Devices  
**Collection method:** HTTP (embedded web UI)  
**Items:** 49  
**Zabbix version:** 7.4+

## Description

Ricoh SP 3710SF printer monitoring — toner levels, paper status, counter and device health via HTTP.

## Requirements

- Zabbix Server 7.4+
- HTTP (embedded web UI) configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
