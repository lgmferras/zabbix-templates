## Descrição

Monitoramento da impressora Ricoh SP 3710SF — níveis de toner, status do papel, contador e saúde do dispositivo via HTTP.

## Requisitos

- Zabbix Server 7.4+
- HTTP (interface web embarcada) configurado no host monitorado

## Importação

1. Acesse **Configuration → Templates**
2. Clique em **Import**
3. Selecione `template.json`
4. Clique em **Import**
