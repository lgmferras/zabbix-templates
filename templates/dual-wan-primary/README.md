# Dual WAN Primary Link

**Category:** Network / Availability  
**Collection method:** Zabbix Agent  
**Items:** 4  
**Zabbix version:** 7.4+

## Description

Primary WAN link availability and latency in a dual-WAN setup.

## Requirements

- Zabbix Server 7.4+
- Zabbix Agent configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
