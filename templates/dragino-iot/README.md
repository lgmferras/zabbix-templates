# Dragino IoT Gateway

**Category:** IoT / LoRaWAN  
**Collection method:** SNMP v2c / HTTP  
**Items:** 57  
**Zabbix version:** 7.4+

## Description

LoRaWAN gateway metrics — packet counters, connectivity status and signal quality.

## Requirements

- Zabbix Server 7.4+
- SNMP v2c / HTTP configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
