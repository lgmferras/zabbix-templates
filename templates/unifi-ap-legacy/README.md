# UniFi AP Legacy

**Category:** Network Devices  
**Collection method:** SNMP v1/v2c  
**Items:** 10  
**Zabbix version:** 7.4+

## Description

Legacy UniFi access point monitoring — client count, uptime, signal strength and traffic.

## Requirements

- Zabbix Server 7.4+
- SNMP v1/v2c configured on the monitored host

## Import

1. Go to **Configuration → Templates**
2. Click **Import**
3. Select `template.json`
4. Click **Import**
